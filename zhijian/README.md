# 知简 · 简历智能诊断 Agent

> 基于 Agentic RAG 思想的简历智能诊断平台：上传简历 → 结构化解析 → 加权岗位匹配 → 可视化诊断报告 → Agent 多轮求职问答。

**在线演示**：（部署后填入你的链接，如 `https://your-domain.com`）

## 一、项目简介

面向应届生求职场景的数据智能产品。用户上传简历（或粘贴文本），系统自动完成：

1. **结构化解析** — 抽取姓名、教育背景、求职意向、技能、项目/实习经历；
2. **技能归一化** — 同义词词表映射（如 MySQL → SQL、ECharts → 可视化）；
3. **加权岗位匹配** — 简历技能得分与内置岗位知识库（8 个岗位 JD）逐项加权比对，输出匹配分与排名；
4. **意向优先策略** — 识别简历中的求职意向，意向岗位接近榜首时优先作为诊断目标；
5. **可视化诊断** — 技能雷达图（你 vs 岗位要求）、匹配度仪表盘、缺失技能优先级、投递建议榜；
6. **Agent 求职问答** — 基于诊断结果的意图识别 + 多轮对话（岗位推荐 / 缺口分析 / 4 周提升计划 / 薪资行情）。

## 二、技术架构

```
┌─────────────────────────────────────────────────┐
│ 用户交互层  原生 HTML/CSS/JS SPA（零框架依赖）      │
├─────────────────────────────────────────────────┤
│ Agent 编排层  意图路由（intents 关键词匹配）         │
│              ├→ answerJobs / answerGaps / ...    │
├─────────────────────────────────────────────────┤
│ 能力引擎层                                        │
│  · parser.js  规则引擎抽取 + 技能词表归一化          │
│  · scoring.js 加权匹配打分 + 意向优先 + 缺口诊断     │
│  · agent.js   对话生成（可无缝替换为 LLM API）      │
│  · ECharts 可视化（多 CDN 容错 + SVG 优雅降级）     │
├─────────────────────────────────────────────────┤
│ 数据层  JOB_LIBRARY 岗位知识库 / SKILL_LEXICON    │
│        技能词表 / 市场趋势模拟样本                 │
└─────────────────────────────────────────────────┘
```

### 工程亮点

- **渐进增强 + 优雅降级**：ECharts 三个 CDN 依次重试，全部失败自动切换为自绘 SVG 图表——断网/CDN 被墙时功能完整可用；
- **意向优先匹配**：不仅"会什么"，还尊重"想做什么"，目标岗位由求职意向驱动；
- **可解释的评分**：每个匹配分都能拆解为技能权重明细，不是黑盒；
- **零构建零依赖**：纯静态资源，任何静态托管（Nginx / GitHub Pages / Vercel / OSS）开箱即用；
- **版本化缓存策略**：静态资源带 `?v=x.y.z`，升级即时生效。

## 四、目录结构

```
├── index.html        # 单页应用骨架
├── css/style.css     # 设计系统（渐变紫科技风）
├── js/
│   ├── data.js       # 岗位知识库 / 技能词表 / 市场数据
│   ├── parser.js     # 简历解析引擎（规则 + 词表归一化）
│   ├── scoring.js    # 加权匹配打分 + 意向优先 + 缺口诊断
│   ├── agent.js      # Agent 对话引擎（意图路由，LLM 可插拔）
│   └── app.js        # 视图路由 / 渲染 / 图表加载策略
├── test.js           # Node 冒烟测试（node test.js）
└── README.md
```

## 六、设计说明

视觉系统采用「浅灰画布 + 白卡片浮层 + 渐变紫品牌色」的 Stripe 风数据产品语言：
主色 `#635BFF → #8B5CF6`，文字 `#0F172A / #64748B`，成功/警告/错误语义色独立成档，
数字统一 tabular-nums，图表主色锁定品牌紫。
