# 知简 · 简历智能诊断 Agent

> 基于 Agentic RAG 思想的简历智能诊断平台：上传简历 → 结构化解析 → 全方向岗位匹配 → 可视化诊断报告 → Agent 多轮求职问答 + 真实企业投递推荐。

**在线演示**：`https://irisshelter.github.io/zhijian/`（GitHub Pages 静态版，AI 问答自动降级为规则引擎）

## 一、项目简介

面向应届生求职场景的数据智能产品。用户上传简历（或粘贴文本），系统自动完成：

1. **结构化解析** — 抽取姓名、教育背景、求职意向、技能、项目/实习经历，识别院校层级与证书；
2. **技能归一化** — 同义词词表映射（MySQL → SQL、ECharts → 可视化），覆盖数据/研发/产品/运营/设计/职能等多方向技能；
3. **全方向岗位匹配** — 简历技能得分与 20 个多方向岗位（数据分析、前端、后端、算法、产品、运营、设计、财务、人力等）加权比对，输出匹配分与排名；
4. **硬门槛体检** — 学历/院校门槛检查，区分「稳健可投」与「冲刺岗」；
5. **可视化诊断** — 技能雷达图（你 vs 岗位要求）、匹配度仪表盘、缺失技能优先级、薪资区间带图；
6. **真实企业投递推荐** — 基于 27 届秋招/春招/实习真实招聘数据（6362 家企业、47027 条岗位），按简历动态匹配对口企业，分梯队（稳健/冲刺/补强）推荐，支持筛选排序与分页；
7. **Agent 求职问答** — 基于诊断结果的意图识别 + 多轮对话（岗位推荐 / 缺口分析 / 4 周提升计划 / 薪资行情）。

## 二、技术架构

```
┌─────────────────────────────────────────────────┐
│ 用户交互层  原生 HTML/CSS/JS SPA（零框架依赖）      │
├─────────────────────────────────────────────────┤
│ Agent 编排层  意图路由（关键词匹配）+ LLM 可插拔    │
│              ├→ answerJobs / answerGaps / ...    │
├─────────────────────────────────────────────────┤
│ 能力引擎层                                        │
│  · parser.js  规则引擎抽取 + 技能词表归一化          │
│  · scoring.js 六维加权评分 + 硬门槛体检 + 缺口诊断   │
│  · agent.js   对话生成（LLM 优先，规则引擎降级）    │
│  · ECharts 可视化（多 CDN 容错 + SVG 优雅降级）     │
├─────────────────────────────────────────────────┤
│ 数据层  JOB_LIBRARY 岗位知识库 / SKILL_LEXICON    │
│        技能词表 / REAL_COMPANIES 6362 家真实企业   │
└─────────────────────────────────────────────────┘
```

### 工程亮点

- **渐进增强 + 优雅降级**：ECharts 三个 CDN 依次重试，全部失败自动切换为自绘 SVG 图表——断网/CDN 被墙时功能完整可用；LLM 无 Key 或额度用尽时自动降级为规则引擎问答；
- **通用化岗位匹配**：不锁定单一方向，20 个多方向岗位 + 基于岗位关键词的动态企业匹配，换简历即换推荐；
- **可解释的评分**：每个匹配分都能拆解为技能权重明细，不是黑盒；
- **零构建零依赖**：纯静态资源，任何静态托管（Nginx / GitHub Pages / Vercel / OSS）开箱即用；
- **版本化缓存策略**：静态资源带 `?v=x.y.z`，升级即时生效。

## 三、快速开始

```bash
# 方式一：直接双击 index.html 打开（推荐本地起服务体验完整功能）
# 方式二：
python -m http.server 8080
# 访问 http://localhost:8080
```

首次进入点击右上角 **「示例简历」→「开始智能诊断」**，即可体验完整流程。

### 关于 AI 大模型（LLM）配置

本项目 AI 问答默认走 WorkBuddy 云服务免密钥中转。**开源仓库中的 `js/cloud-config.js` 是脱敏占位 Key**，不启用真实 AI（自动降级为规则引擎问答），以避免你的调用额度被白嫖。

若要启用 AI 大模型：

1. 复制 `js/cloud-config.example.js` 为 `js/cloud-config.js`；
2. 填入你自己的 `publishableKey`；
3. 该文件已加入 `.gitignore`，请勿将真实 Key 提交到公开仓库。

## 五、数据说明

- 真实企业数据来自「27 届秋招/春招/实习汇总表」（10650 行原始招聘记录）；
- 按公司名去重后得到 6362 家全方向企业（国企/民企/外企），展开为 47027 条岗位；
- 企业匹配基于岗位关键词动态计算，用户提交简历后按目标岗位初筛对口企业；
- 数据为招聘季静态快照，投递链接自带时效性兜底（点进去看岗位是否仍开放）。

## 六、设计说明

视觉系统采用「深空蓝紫底 + 霓虹渐变 + 卡片浮层」的科技感数据产品语言：
主色 `#7C6CFF → #A855F7 → #22D3EE`，深色背景 `#0B0E1A` 系，文字 `#E8EAF2 / #9AA3B8`，
成功/警告/错误语义色独立成档（绿=稳健/橙=冲刺），数字统一 tabular-nums。
